# Kredex: Decentralized Micro-Lending

Welcome to the **Kredex Documentation**! Kredex is a decentralized micro-lending and borrowing platform built on the Stellar network using Soroban smart contracts. 

## Overview

Kredex connects lenders looking for passive yield with borrowers who need quick, transparent access to capital. By utilizing Soroban smart contracts, Kredex ensures that all loan agreements, interest calculations, and collateral management are fully decentralized, trustless, and securely recorded on-chain.

## Core Features

- **On-Chain Reputation:** Dynamic scoring where good borrowers earn reputation points tracked natively on Soroban.
- **Soulbound NFTs:** High-reputation users receive non-transferable NFT badges (Gold/Platinum) which unlock higher borrowing limits.
- **Automated Liquidity Pools:** Lenders can deposit into automated pools for instant yield diversification instead of manually picking loans.
- **Stellar Disbursement:** Admins can fund up to 500 approved loans at once using the Stellar Disbursement Platform (SDP) engine.
- **Passwordless Auth:** Login seamlessly using biometric Passkeys or your Freighter wallet signature.
- **SEP-12 KYC Integration:** Out-of-the-box compliance acting as a native Stellar KYC server.
